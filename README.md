# Hollins Rota exports

Files the support desk at Hollins Rota exported for the people who ask questions about our customers. The live data (tickets, in-app assistant chats, recorded calls, accounts) sits in the analysis workspace; these are the loose files that go with it.

- `data/support_tickets_export.csv`: the desk's tickets from mid September to the end of October, as exported from the desk tool.
- `data/quickbooks_line_items.xlsx`: the bookkeeping workbook; the tab `INPUTS QB: Quickbook Line Item Inputs` is the line items.
- `docs/qa-criteria.md`: the ten yes/no questions the leads score a solved ticket against.
- `docs/sos-routing-guide.md`: when the desk offers a call instead of a written reply.
